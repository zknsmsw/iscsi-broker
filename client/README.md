# 客户机客户端（agent）

给无盘 Windows 客户机用的常驻小程序，实现三件事：

| 功能 | 说明 |
|------|------|
| 远程关机 / 重启 | 后台「客户机控制」页点一下，客户机 3 秒后关机 / 重启 |
| **Z 盘（网盘）** | **默认自动挂载**：右下角托盘图标；未登录时 Z 盘 = 服务器的「通用文件」（只读），用户在托盘里**登录自己的网盘账号**后 Z 盘变成他自己的网盘（可写，里面仍能看到只读的「通用文件」）。无盘客户机重启后自动恢复，不用再点 |
| VNC 控制 | 后台点「启用 VNC」拉起客户机上的 VNC 服务端，网页里直接看画面并操作 |

设计上客户机**不开放任何入站端口**：agent 每隔几秒主动向服务器心跳（`POST /agent/poll`），
管理员的指令随心跳下发，执行完再回报（`POST /agent/result`）。所以客户机在 NAT / 防火墙
后面也能被控制。

客户端是**一个 exe、两种身份**（同一份母盘，所有机器共用）：

```
SYSTEM 身份（开机自启的计划任务，会话 0）
  ├── 心跳 / 收指令：关机、重启、启停 VNC
  ├── 配好 Windows WebDAV 重定向器（注册表 + WebClient 服务，只有 SYSTEM 改得动）
  └── 用户登录后，在用户会话里拉起托盘进程
用户身份（托盘进程，用户会话里）
  ├── 右下角图标 + 右键菜单：登录网盘 / 注销 / 打开 Z 盘 / 重新挂载 / 查看日志
  └── 挂 Z 盘（盘符映射是"每个登录会话一份"，必须在用户会话里做）
```

```
母盘里：C:\iscsi-broker-agent\
        ├── iscsi-broker-agent.exe     开机由计划任务以 SYSTEM 运行；同一 exe 的 tray 模式在用户会话跑托盘
        ├── agent.ini                  服务器地址 + 接入令牌 + VNC 路径（全机共用，不区分机器）
        ├── agent.state                运行期状态缓存
        └── agent.log                  运行日志
浏览器（管理员） --8080--> 服务器 --TCP 5900--> 客户机 VNC 服务端
                        └--HTTP WebDAV--------> 客户机 Z 盘
```

> 每台机器不一样的东西（是否允许挂 Z 盘、默认用户名、在线/VNC/Z 盘状态、指令）全部存在
> **服务器上、以 MAC 为主键**；客户机里不放任何"每机不同的配置"。所以一份母盘可以发给所有机器。

---

## 1. 编译

在任意 Windows 10/11 上双击 `build.bat`（或命令行执行）。它用系统自带的
`.NET Framework` 编译器，**不需要装 Visual Studio / .NET SDK**。

产物：`client\dist\iscsi-broker-agent.exe`（单个小 exe，目标机**不需要**装 .NET 运行时，
Win10/11 自带）。`client\dist\` 是构建产物目录，不进仓库。

> 想改代码：只改 `Agent.cs`（C# 5 语法，因为用的是系统内置的旧版 csc），重新跑 `build.bat`。

## 2. 在母盘里装一次

客户机是无盘的，普通模式下改动都落在叠加盘、空闲后会被删掉，所以客户端必须做进母盘：

1. iPXE 菜单选 **Admin Mode**（回写模式）启动一台客户机，把系统配置做完；
2. 建议先装一个 VNC 服务端（TightVNC / UltraVNC 都行），**装成 Windows 服务**
   （服务模式才能看到登录界面；直接拉起 exe 只能看到当前桌面）；
3. 新建目录 `C:\iscsi-broker-agent\`，把 `iscsi-broker-agent.exe` 和 `agent.ini` 放进去；
4. 编辑 `agent.ini`：
   - `[server] url=` 填服务器地址（**Web 后台端口 8080**，不是 iPXE 的 5000）；
   - `[server] token=` 抄服务器后台「客户机控制」页上的**接入令牌**；
   - `[vnc] service=`（推荐，填 VNC 注册的服务名，例如 `tvnserver`）或 `[vnc] exe=`；
5. 管理员身份执行（在客户机里）：

   ```cmd
   C:\iscsi-broker-agent\iscsi-broker-agent.exe test      :: 检查配置/MAC 读得对不对
   C:\iscsi-broker-agent\iscsi-broker-agent.exe install   :: 装成“开机以 SYSTEM 运行”并立即启动
   ```

6. 关机（母盘就绪，之后所有普通模式启动的客户机都自带 agent）。

### agent.ini

```ini
[server]
url=http://10.1.1.1:8080    ; 服务器 Web 后台地址
token=                      ; 后台「客户机控制」页上的接入令牌（所有客户机共用这一把）
interval=3                  ; 心跳间隔（秒），指令随心跳下发
mac=                        ; 一般留空；自动取“默认网关网卡”的 MAC。多网卡/测试机才写

[vnc]
exe=                        ; VNC 服务端 exe 全路径（与 service 二选一）
args=-run                   ; 启动参数
service=tvnserver           ; VNC 注册的 Windows 服务名（推荐，可看登录界面）
port=5900                   ; 只用于后台展示

[dav]
letter=Z                    ; 网盘映射到哪个盘符
```

> 这几个值**所有客户机都一样**（母盘共用，本来也不该有每机差异）。想给某台机器单独设置，
> 在服务器后台「客户机控制」页按 MAC 设置，不要改 `agent.ini`。

## 3. 客户机上的托盘（用户日常用的）

右下角托盘图标（蓝底白 Z），**右键**菜单：

| 菜单项 | 作用 |
|---|---|
| 状态（灰色） | 未登录 / 已登录：xxx |
| 登录网盘… | 输网盘账号密码 → Z 盘换成自己的网盘（可写） |
| 注销网盘 | Z 盘恢复成只读的「通用文件」 |
| 打开 Z 盘 | 打开资源管理器 |
| 重新挂载 | 盘符掉了（比如休眠唤醒后）点一下重挂 |
| 查看日志 | 打开 agent.log |
| 退出托盘 | 只关托盘进程，SYSTEM 那个还在跑（下次心跳会再拉起来）；要彻底停用请卸载开机任务 |

行为说明：

- **不记住登录**：网盘账号密码只在用户输入时用一次，服务器换一个 12 小时的会话令牌给托盘，
  令牌**只存在内存里**（无盘机器每次开机都是新的，所以每次开机都要重新登录一次）。
  账号密码不会写到客户机任何地方。
- 托盘启动时会先挂**只读公共盘**（用 MAC + 接入令牌认证），不需要任何人登录。
- 登录后 Z 盘根目录 = 你自己的网盘；里面能看到只读的「通用文件」目录（和网页版网盘一致）。
- 「默认用户名」可以在后台按 MAC 设置，托盘登录框会自动填上，省得每台机器输用户名。

## 4. 后台怎么用（/web/clients 「客户机控制」）

- **接入令牌**：页首显示当前令牌，可一键重置（重置后所有客户机都要改 `agent.ini`）。
- **客户机表格**：MAC / 主机名 / IP / agent 在线状态 / Z 盘（含"已登录 xxx"）/ VNC 状态 /
  最近一条指令结果；只有 iPXE 记录、没有 agent 心跳的机器会标成「未装 agent」。
- **关机 / 重启**：立即执行。
- **启用 VNC / 停用 VNC**：VNC 起来后该行出现「VNC 画面」链接，打开就是内嵌的 noVNC 页面
  （需要 VNC 自己的密码时页面会提示输入）。
- **停用网盘 / 启用网盘**：默认是挂载状态（Z 盘=只读通用文件）。停用会让该机托盘退出、
  Z 盘卸载；启用则下次心跳时把托盘重新拉起来。
- **默认用户名**：只用于预填客户机托盘的登录框，**不保存密码**。

## 5. 注意与排错

- **令牌等于控制权**：拿到令牌就能让任意 MAC 的客户机执行关机/重启/挂 VNC，也能读只读公共盘。
  只在内网使用；怀疑泄漏就在后台重置。用户自己的网盘**不受令牌影响**（要各自的账号密码）。
- **MAC 是自报的**：局域网二层本来就挡不住伪造（和联网控制一样），按内网信任使用。
- **VNC 密码**：由 VNC 服务端自己管（agent 不改它），在网页里按提示输入即可。
- **网盘是明文 http 的 WebDAV**：Windows 默认禁止在 http 上用 Basic 认证、且限制单文件
  50MB；SYSTEM 进程启动时会自动改好注册表（`BasicAuthLevel=2`、`FileSizeLimitInBytes`、
  `AuthForwardServerList` 只放行本服务器）并拉起 WebClient 服务——所以**首次装好后重启一次**
  最保险。
- **日志**：`C:\iscsi-broker-agent\agent.log`（托盘与 SYSTEM 进程写同一个文件）。
- **排错命令**：

  ```cmd
  iscsi-broker-agent.exe test              :: 打印配置、MAC、VNC 状态、图标来源
  iscsi-broker-agent.exe once              :: 只跑一轮心跳
  iscsi-broker-agent.exe run               :: 前台运行 SYSTEM 部分（看实时日志）
  iscsi-broker-agent.exe run --dry-run     :: 只打印将要执行的指令，不真关机/真映射盘
  iscsi-broker-agent.exe selftest --user <账号> --pwd <密码>
                                           :: 命令行自检：心跳/状态/登录换令牌/注销各打一次
  iscsi-broker-agent.exe tray              :: 手动起托盘（调试用；会尝试隐藏控制台窗口）
  iscsi-broker-agent.exe uninstall         :: 删掉开机任务
  ```

- **托盘图标不见了**：确认有用户登录（SYSTEM 会话里画不出托盘）；`agent.log` 里找
  「已在会话 N 启动托盘」；手动 `iscsi-broker-agent.exe tray` 试一下。
- **Z 盘是空的 / 打不开**：先看托盘右键菜单里的状态；未登录时 Z 盘是只读的「通用文件」，
  管理员要在后台「通用文件」页先传点东西；登录后才能看到自己的网盘。
- **Z 盘登录后还是只读**：检查是否真的登录成功（托盘状态显示"已登录：xxx"），以及
  WebClient 服务是否在跑（`sc query WebClient`）。
- 后台「客户机控制」页看不到机器：确认 `agent.ini` 里的 url 通（浏览器打开
  `http://<服务器>:8080/` 试）、令牌没抄错、任务在跑（`schtasks /Query /TN iSCSI-Broker-Agent`）。
